## Decisions still open

These change the copy, so the founding team should settle them before launch:

1. **Payment placement.** "You'll see it before you decide" appears only if the piece is shown before payment.
2. **Uniqueness.** Define what is unique (image, seed, composition, issuance) before any "unique" line.
3. **Engine description.** Confirm the exact words for how Endless generates.
4. **The number 2,212.** Publish the real reason and the remaining count.
5. **Physical piece.** Core inclusion, add-on or later; it changes *What you receive*.
6. **Spelling market.** *Recognise* (spine) or *recognize* (US site).
